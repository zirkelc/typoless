Models

  • The downloaded model is now Gemma 4 E2B, in place of Gemma 4 E4B. It is 1.5 GB smaller, about three times faster, and corrects better in every language that was measured: 80% of English messages exactly right against 43%, and 79 to 81% in Spanish, French, Italian, Dutch and Portuguese. The larger model found slightly more errors and then changed text that was already right, which is the one thing this app is meant not to do.
  • Each model now says what it is worth beside what it costs, so a smaller download is no longer the only thing you have to go on.
  • The advice beside each language follows the new measurements. The downloaded model measures best in five of the seven languages now. English and German stay with the built-in model.
  • If you had Gemma 4 E4B selected, Typoless uses the new model and downloads it the first time you correct something. The old weights stay in ~/.cache/huggingface until you remove them.
