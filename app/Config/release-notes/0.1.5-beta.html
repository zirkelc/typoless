Corrections

  • Short text is no longer passed over. A line like "chekc this todo" reads as another language once the typo takes the letters the recogniser judges by, and Typoless used to leave it alone without saying so.
  • A line too short to have a language of its own now follows the message around it, so an email signed with your name is not read as English in the middle of German.

History

  • Every correction is kept, including the ones that changed nothing. What Typoless decided not to do is often the thing worth reporting.
  • Each entry says which language it read the text as, what it changed, and for anything it did not change, why: a rule you turned off, protected text, a language that is not switched on, or a reply that was a rewrite.
  • The list is a table now, with filters for app, language and what happened, and each change is marked where it is rather than the whole stretch between the first and the last.
  • A report on the tracker carries all of it, so the first question about a bug report is already answered in it.
