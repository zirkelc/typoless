Updates

  • Typoless checks for a new version from the first launch, and no longer asks a question about it on the second. The switch is in Settings, under General.
  • A new version marks the menu bar icon instead of opening a window in the middle of what you are writing. The menu says so, and you decide when to look.
  • The update window now says what is in the release. This page is it.
  • Settings gained a Check Now button, and says when it last looked.

Nothing is ever installed without you.
